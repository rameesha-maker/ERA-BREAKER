# ERA-BREAKER
ITS A GAME WHICH USES PYTHON AS BACKEND (PYGAME). IT SETSS PLAYER INTO DIFFERENT ERAS OF TOKYO WHERE HE FACES CHALLENGES AND IN ORDER TO SOLVE THEM HE GETS THE ICONIC DORAEMON POWERS IT ALSO HAS A DASHBOARD WITH THE ARROW KEYS COPTER FUEL BAR AND PROGRESS BAR AS WELL, AND NOW THERE IS A TIMER THAT WILL RECORD HOW MUCH TIME YOU SPENT ON EACH ERA.,.
each era has its own set of difficulties and challenges which can only be surpassed by using the powers, like a platform is so high that player can only reach it using the bamboo copter,another gadget time machine stores the last 5 second movement of player and can rewind.
the copter works in accordance with physical circumstances like gravity,terminal velocity,fuel and such other things
the time machine equally imitates the movement and takes the player back
the game also has a how to play part where you can see how to play the game.
